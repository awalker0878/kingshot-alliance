# Framework translations

Validation, authentication, and password-reset translations are adapted from [Laravel Lang](https://github.com/Laravel-Lang/lang/tree/dfd5466ebdab22a01b3587bcdac2f105fd3ce597) under the [MIT license](LICENSE-Laravel-Lang.md). Only inert translation data was imported; no package or scripts were installed. Keys follow the English language files in the repository's locked Laravel framework version.
