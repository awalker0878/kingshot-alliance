# Intelligence

Observational and analytical state: Player/Alliance/roster observations, ingestion/reconciliation, uploaded game evidence and immutable extraction/review provenance, contribution ledger, reporting/exports/trends, shared intelligence/grants/history and diplomacy analysis.

`Evidence` owns uploaded sources and attempts to interpret/review them. It never becomes the writer for the resulting GameWorld, Alliance or Operations domain state; reviewed values cross through scalar owner contracts.

Neutral GameWorld identity is never duplicated here as writable identity state.
