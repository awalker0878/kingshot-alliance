# Kingdoms domain

`Kingdoms` is the canonical owner for approved game/kingdom reference capabilities.

The first approved scope is [`KINGDOMS-001` — Kingdoms roster intelligence](../../../docs/product/kingdoms-roster-intelligence-increment.md), covering first-class Kingdom references, separate game-player identity, alliance-scoped roster entries, historical snapshots, manual/CSV workflows, and roster intelligence.

**No runtime implementation is present yet.** Approved roadmap scope must not be treated as implemented capability until the increment is built, validated, documented, and accepted.
